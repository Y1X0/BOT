# 🎧 بوت الكول (تشغيل الأغاني على المكالمة الجماعية)

مشروع **منفصل** عن بوت الإدارة. تشغيل الصوت داخل الكول **مستحيل عبر Bot API**، فهذا
البوت يستخدم:

- **بوت أوامر** (توكن جديد من BotFather) — يستقبل الأوامر.
- **حساب مساعد (Userbot)** — حساب تيليجرام حقيقي يدخل الكول ويبثّ الصوت عبر
  WebRTC باستخدام `py-tgcalls`.
- **yt-dlp + ffmpeg** — للبحث وجلب الصوت.

---

## المتطلبات (لازم تجهّزها)

1. **API_ID و API_HASH**: من https://my.telegram.org ← API development tools.
2. **توكن بوت جديد**: من [@BotFather](https://t.me/BotFather) — بوت **منفصل** عن بوت
   الإدارة (نفس التوكن ما بيشتغل بمكانين).
3. **حساب مساعد**: رقم/حساب تيليجرام إضافي (مش حسابك الأساسي ومش البوت). منه نولّد
   `SESSION_STRING`.
4. **استضافة تدعم WebRTC/UDP**: يُفضّل **VPS** (مثل Ubuntu). منصّات مثل Railway
   غالباً ما تنجح مع بثّ الصوت.

---

## التشغيل خطوة بخطوة

```bash
cd music-bot
pip install -r requirements.txt

# 1) ولّد جلسة الحساب المساعد (سجّل دخول بحساب المساعد، مش البوت):
python gen_session.py
#   → انسخ SESSION_STRING

# 2) جهّز الإعدادات:
cp .env.example .env
#   → عبّي API_ID / API_HASH / BOT_TOKEN / SESSION_STRING

# 3) شغّل:
python main.py
```

### أو عبر Docker

```bash
docker build -t music-bot .
docker run --env-file .env music-bot
```

## بالقروب (مهم جداً)

- أضف **بوت الأوامر** و**الحساب المساعد** كلاهما إلى القروب.
- اجعل **الحساب المساعد أدمن** مع صلاحية **إدارة المكالمات الصوتية** (Manage Video
  Chats). بدونها ما بيقدر يفتح/يبثّ بالكول.

---

## الأوامر

| الأمر | الوظيفة |
|------|---------|
| `افتح كول` | يفتح مكالمة جماعية |
| `تشغيل <اسم الأغنية>` | يشغّل أغنية (أو بالرد على رسالة فيها الاسم) |
| `تخطي` | الأغنية التالية من الطابور |
| `ايقاف` / `كمل` | إيقاف مؤقت / استئناف |
| `الطابور` | قائمة الانتظار |
| `سكر كول` | ينهي المكالمة ويطلّع المساعد |
